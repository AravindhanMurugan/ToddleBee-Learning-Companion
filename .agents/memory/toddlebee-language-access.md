---
name: ToddleBee language access
description: Product requirement for the learner and parent language experience.
---

Children and parents may choose or change ToddleBee's learning language at any time. English and Tamil are the supported languages.

**Why:** The user explicitly asked for language choice by either the child or parent, not a one-time setup choice.

**How to apply:** Keep the language switch available on learner and parent screens, persist it across routes, and present the main learning interactions in the selected language.
