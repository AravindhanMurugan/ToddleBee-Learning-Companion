## 1. PRODUCT VISION

ToddleBee is a personalized AI learning companion for children aged 8–12.

It helps students:

- Learn school concepts through simple, age-appropriate explanations.
- Listen to explanations using AI-generated audio.
- Learn in Tamil or English.
- Practice through interactive quizzes.
- Receive alternative explanations when they answer incorrectly.
- Understand their learning patterns through a simple progress dashboard.
- Ask an AI tutor for additional help.
- Receive educator support when the AI detects repeated difficulties.

The first demonstrable lesson must be **Grade 4 Mathematics: Fractions**.

Demonstrate one complete learning journey:

**Choose language → Start lesson → Listen → Learn → Take quiz → Receive feedback → View learning insights.**

Do not build multiple full subjects. Design the code so additional lessons can be added later.

## 2. TECHNOLOGY STACK

Use the following stack unless the Replit environment has a clear compatibility issue:

- Frontend: React, TypeScript, Vite.
- Styling: Tailwind CSS or the simplest available responsive styling system.
- Backend: Node.js with Express and TypeScript.
- Database: PostgreSQL using `DATABASE_URL` if easily available. Otherwise, use a small persistent JSON/file-backed store suitable for a hackathon and deploy it with a persistent disk. Never depend on an ephemeral filesystem for production persistence.
- AI: Use an available model API through a server-side adapter if credentials are provided.
- Voice: ElevenLabs text-to-speech API.
- Agentic AI: AgenticOrg TypeScript SDK or its currently documented supported API.
- Payments: Pine Labs-approved sandbox integration, using the correct product and API documentation provided for the hackathon.
- Hosting: Render for the deployed web application.

Keep the project simple: one frontend, one backend, and one database if available.

Do not introduce Redis, microservices, Kubernetes, a complex authentication platform, or a separate vector database.

Use environment variables for every secret. Never put API keys in browser code, GitHub, logs, or public responses.

## 6. FRACTIONS LESSON

Create a complete lesson about fractions with five short teaching sections.

**Section 1: What is a fraction?**

Explain that a fraction represents part of a whole.

**Section 2: Pizza example**

Display a pizza divided into four equal slices. Explain that one slice out of four is `1/4`.

**Section 3: Chocolate example**

Display a chocolate bar divided into equal parts. Explain numerator and denominator.

**Section 4: Equivalent fractions**

Show visually that `1/2` is equivalent to `2/4`.

**Section 5: Everyday challenge**

Ask the child to identify the fraction represented by a simple illustration.

Each lesson section must include:

- A heading.
- A short explanation.
- A simple visual illustration.
- A “Listen to explanation” button.
- An “Explain another way” button.
- An “I understand” button.
- A progress indicator.

Provide both English and Tamil lesson content. Author and verify the Tamil content carefully. Never return English content while falsely labeling it as Tamil.

Do not wait for an AI API to load the basic lesson. Ship the lesson content with the application so it works immediately.

When “Explain another way” is clicked:

1. Identify the current concept.
2. Use the student's selected language.
3. Generate a simpler explanation using a different example when the AI is available.
4. If AI is unavailable, use a curated alternative explanation.
5. Record the event in the student's learning activity.

The tutor should encourage reasoning. It must not shame a student for a wrong answer or reveal every answer before the student has tried.

## 8. TODDLEBEE LEARNING COACH AGENT

Build a learning agent called **“ToddleBee Learning Coach.”**

Its responsibility is to guide the student's learning session rather than merely answer questions.

Inputs:

- Student's selected language and grade.
- Current concept.
- Current and previous quiz answers.
- Number of incorrect attempts.
- Sections completed.
- Previous explanations shown.

The agent must:

1. Identify the concept being studied.
2. Examine the learner's answer history.
3. Identify a possible misconception, without treating a single wrong answer as a definitive diagnosis.
4. Choose a teaching strategy.
5. Provide a short explanation or hint.
6. Generate an appropriate next question.
7. Recommend additional practice when needed.
8. Recommend educator review when difficulties persist or the AI is uncertain.

Use structured output with fields similar to:

```json
{
  "concept": "fractions",
  "observed_pattern": "may be confusing numerator and denominator",
  "confidence": 0.78,
  "teaching_strategy": "visual_example",
  "explanation": "Imagine a pizza cut into four equal slices...",
  "next_action": "show_targeted_question",
  "needs_human_review": false,
  "reason": "The learner has made repeated errors on this concept."
}
```

Validate model output on the backend before using it.

Do not claim the model can definitively diagnose a child's abilities or learning disabilities.

## 10. QUIZ AND ADAPTIVE LEARNING

Create a five-question quiz that starts after the lesson.

Questions should test:

1. Identifying a fraction.
2. Understanding the numerator.
3. Understanding the denominator.
4. Recognizing equivalent fractions.
5. Applying fractions to an everyday situation.

Use multiple-choice answers and one question at a time.

Each question must have:

- Four possible answers.
- A progress indicator.
- Immediate feedback.
- A short explanation after answering.
- A next-question button.

Store the answer, correctness, concept, attempt count, response time where available, and hint usage.

Adaptive behavior:

- Correct answer: acknowledge the reasoning and move forward.
- First incorrect attempt: show a hint and let the child retry.
- Repeated incorrect attempts: present a simpler visual explanation and an easier question testing the same concept.
- Repeated difficulty: flag the concept for educator review.
- Strong performance: suggest a slightly more challenging practice question.

Do not repeatedly penalize the student for the same misunderstanding.

The quiz must work using predefined questions without an AI API. AI may personalize the explanations, but objective answer checking must use trusted server-side answer keys.

Use ToddleBee's supportive tone. The mascot can offer encouraging messages such as “Let’s try a different way!” or “Great effort — every try helps us learn.”
